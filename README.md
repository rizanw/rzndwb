# rzndwb.xyz

Source for my personal site, **[rzndwb.xyz](https://rzndwb.xyz)**: a single page with what I'm up to, things I've built, and things I've written.

It's one static `index.html` with a small stylesheet in `assets/css/`. No framework and no build step beyond GitHub Pages. Pushing to `master` deploys it through the Jekyll workflow in `.github/workflows/`.

To preview locally, run any static server from the repo root:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```
